# 📱 **Truth Table Calculator in JavaScript** 🧠

A modern, interactive **Truth Table Calculator** built with **HTML**, **CSS**, and **JavaScript**.  
This project allows users to input logical expressions and automatically generate full truth tables with step-by-step evaluation.

---

## 🎯 **Features**

- 🧠 **Logical Expression Solver**: Supports variables (`P, Q, R, S, T`) and logical operators.
- 🔢 **Automatic Truth Table Generation**: Instantly computes all possible truth combinations.
- 🎨 **Icon-Based UI**: Clean calculator interface using custom button icons.
- 🔒 **Input Lock System**: Prevents editing after solving until reset.
- 🔁 **Solve New Expression Button**: Sticky reset button for better workflow.
- 📖 **Help Modal**: Full-screen guide explaining syntax and operators.
- 🎶 **Sound Effects**: Button clicks and actions have audio feedback.
- ✂️ **Smart Backspace (C Button)**: Deletes one character at a time.
- 🎯 **Sub-expression Evaluation**: Displays intermediate logic steps.

## 🧑‍💻 **How to Use**

1. Open the `index.html` file in your browser.

2. Use the calculator buttons to input a logical expression.

3. Supported operators:

   - `¬` → NOT  
   - `∧` → AND  
   - `∨` → OR  
   - `→` → IMPLIES  
   - `↔` → BICONDITIONAL  
   - `⊼` → NAND  
   - `⊽` → NOR  
   - `⇹` → XOR  

4. Press `=` to generate the truth table.

5. View:
   - Variable combinations  
   - Sub-expressions  
   - Final result  

6. Use `C` to delete characters.

7. Click **"Solve New Expression"** to reset and start again.
